# 📝 Instrucciones para Agregar tus Logos

## Paso 1: Copiar las Imágenes

Por favor, copia manualmente tus 3 imágenes de logo a esta carpeta:

```
C:\Users\USUARIO\.gemini\antigravity\scratch\don-segurito\assets\images\
```

## Paso 2: Renombrar las Imágenes

Renombra tus 3 imágenes con estos nombres exactos:

1. **Logo principal** (el que prefieras para el header):
   - Renombrar a: `logo-main.png`

2. **Logo con técnicos** (para el hero section):
   - Renombrar a: `logo-technicians.png`

3. **Logo completo** (para la sección "Sobre Nosotros"):
   - Renombrar a: `logo-complete.png`

## ✅ Archivos Necesarios

```
assets/images/
├── logo-main.png          ← Logo para header y footer
├── logo-technicians.png   ← Logo con técnicos para hero section
└── logo-complete.png      ← Logo para sección "Sobre Nosotros"
```

## 🎯 ¿Dónde se Usa Cada Logo?

- **logo-main.png**: Header (navegación), Footer, Favicon
- **logo-technicians.png**: Sección principal (Hero)  
- **logo-complete.png**: Sección "Sobre Nosotros"

## 🚀 Después de Copiar

Una vez renombradas y copiadas las imágenes:

1. Abre `index.html` en tu navegador
2. Deberías ver tus logos en todas las secciones
3. ¡Listo! El sitio está completo con tus logos

---

**Nota:** Si prefieres usar el mismo logo en todas partes, simplemente copia tu logo favorito 3 veces con los 3 nombres diferentes.
